not a permitted default.

## State blueprints

- Loading: preserve the final composition with rule-and-text skeletons, not generic cards.
- Empty: explain which real action creates evidence and link to that action.
- Degraded/SSE offline: copper ledger banner; historical evidence remains usable.
- Access denied: sealed ledger field naming current role and required authority.
- Revoked: permission envelope closes in red; prior evidence remains readable.
- Halted: global shell acquires a red/proof containment band; emergency controls stay reachable.
- Error: exact safe error, correlation where supplied, and bounded retry.

## Guided Demo chain

Command Center Spine → normal action → exposure reservation → rogue denial →
Decision Explainer → rogue revoke → normal-agent continuity → fleet halt → gateway
acknowledgements → failed-closed request → Evidence Thread → integrity proof → safe resume.
Every transition is triggered by or reconciled with backend state.
